# Sitio web del negocio

## Estructura
- `index.html`: contenido y textos (promociones, horarios, historia, políticas).
- `css/styles.css`: diseño (colores en las variables `:root` al inicio).
- `js/main.js`: tus datos (nombre, WhatsApp, menú y precios) arriba, en `EDITA AQUÍ TUS DATOS`.
- `img/`: tus fotos.
